# new-game

ゲームの名前は（仮）「秘密を暴け」


ゲームの概要
・PCで動作すること
・指定したAIに指定した秘密を与えること
・いくつかのエンディングがあること
・どのキャラクターの秘密を暴くのかのセレクト画面
・自由記入された文章から指定されたワードによって好感度やストレス値の増減や、それらによる対応の変化と自白の判定をできるパラメータを設定すること


## 現在の状態

`index.html` をブラウザで開くと遊べる（`img/` と `audio/` フォルダも一緒に置くこと）。外部ライブラリなし、HTMLファイル1つで動作。

### ファイル構成
```
index.html                             ゲーム本体（HTML・CSS・JavaScript）
img/young_criminal_anime_bright.png    田中の画像
audio/fuon.mp3                         BGM（不穏）
README.md                              この説明
```

### 画面の流れ
タイトル → キャラクター選択 → 会話（取り調べ） → 秘密の回答（バインダー風の自由入力） → 結果・エンディング
キャラクター選択画面の「⚙ 設定」から、ミュージック音量・実績・フラグ管理・質問一覧を見られる。

### 実装済み
| 項目 | 状態 |
|---|---|
| PCで動作 | ○ ブラウザで動作 |
| キャラクター選択画面 | ○ 田中のみ選択可。他2枠は「準備中」 |
| 会話 | ○ 選択肢形式。最大10ターン（自白状態では延長可）、「会話を終了する」ボタンでいつでも回答へ |
| 好感度・ストレス | ○ 選択肢ごとに増減。値によって返答・様子・画像の色味が変化 |
| 自白 | ○ 好感度＋ストレスが一度でも80以上になると自白可能領域に入り（以降は数値が下がっても維持）、「自白」ボタンが押せる。押すと沈黙の選択肢が「自白させる」に変わり、選ぶと自白状態へ移行 |
| 秘密の回答 | ○ 自由入力。ユニークワードでクリア、追加情報を分数（当てた数 / 全体）で表示 |

### 田中（実装済みキャラクター）
- 田中 涼介、28歳。駅前銀行強盗の実行犯として逮捕済み。「一人でやった」と言い張り、共犯者を庇っている。
- 隠している秘密：外で見張りをしていた幼なじみの友人「茉奈」。盗んだダイヤは茉奈の家の庭に埋めてある。
- 画像：`img/young_criminal_anime_bright.png`
- 初期値：好感度 30 / ストレス 30。ストレス 100 で取り調べ打ち切り。
- 音楽：`audio/fuon.mp3`

### 回答の判定
- 入力は表記ゆれ（全角半角・カタカナひらがな・大文字小文字・空白記号）をそろえてから、指定の1単語が含まれるかで判定する。
- クリア（ユニークワード）：茉奈（まな / マナ / mana）
- 追加情報（5つ）：女性（女・彼女 など） / 共犯者（共犯・見張り・仲間 など） / 友人（友人・友達・幼なじみ など） / ダイヤ（ダイヤ・宝石 など） / 庭に埋めた（庭・埋 など）

### エンディング
| | 条件 |
|---|---|
| END 1：真相解明 | クリア ＋ 追加情報すべて |
| END 2：核心への到達 | クリア |
| END 3：届かなかった名前 | クリアなし・追加情報あり |
| END 4：迷宮入り | 何も当てられなかった |

### フラグ管理
- 質問への返答（好感度・ストレスで分岐）によってフラグが立ち、そのフラグが揃うまで出ない質問がある。
  - `requires`：進行フラグ。決められた返答を受けてからでないと出ない質問。
  - `mentions`：事実フラグ。答えに関わる内容は、キャラクター自身が口にするまで選択肢に出ない。
  - 条件を満たさず失敗した質問は、後でもう一度選べる（`keep: true`）。
- 田中のフラグ

| フラグ | 種類 | 立つきっかけ |
|---|---|---|
| homemade 手料理の話 | 進行 | 「食事は取れていますか？」 |
| money 金が必要だった | 進行 | 「どうして銀行強盗なんて？」 |
| someone 大事な人の存在 | 進行 | 「手料理…誰かに？」（好感度40以上） / 「そのお金は何に？」（好感度45以上） |
| outside 外の映像を気にした | 進行 | 「防犯カメラの映像を…」（ストレス50以上） |
| trust 心を開いた | 進行 | 「誰かを守ろうとしているのは分かっています」（好感度45以上） |
| shaken 心が揺らいだ | 進行 | 自動：好感度＋ストレスが一度でも80以上になる |
| accomplice 共犯者がいる | 事実 | 「本当に一人で？」（ストレス50以上） / 「外に何か映ると困る？」 / 「事件の日は一人で？」（好感度55以上） |
| woman 相手は女性 | 事実 | 「その人はどんな存在？」（ストレス60以上 または 好感度50以上） / 自白させる |
| friend 幼なじみの友人 | 事実 | 「その人はどんな存在？」（好感度50以上） / 自白させる |
| diamond 盗んだのはダイヤ | 事実 | 「盗まれた物はどこに？」（ストレス55以上） / 自白状態「事件の日のことを最初から」「盗んだ物は今どこに？」 |
| garden 茉奈の家の庭に埋めた | 事実 | 「盗まれた物はどこに？」（ストレス75以上） / 自白状態「盗んだ物は今どこに？」 |
| name 名前は茉奈 / confessed 自白 | 事実 / 結末 | 「自白」ボタンを押して「もう、全部話してしまいませんか。（自白させる）」を選ぶ |

### 自白
- **自白可能領域**：好感度＋ストレスが一度でも80以上になり、心が揺らいだ（shaken）状態。一度入れば、その後数値が下がっても領域は維持される。
- 会話画面の「会話を終了する」の隣に「自白」ボタンがある。自白可能領域のときだけ押せる（領域に入ると「今なら『自白』ボタンで自白に持ち込めそうだ。」と表示）。
- 「自白」を押すと「自白：選択中」になり、「（黙って、相手の目を見つめる）」が「……もう、全部話してしまいませんか。（自白させる）」に変わる。もう一度押すと元に戻る。
- 「自白させる」を選ぶと自白状態への移行が確定する。
- 選ぶと**自白状態**に移行し、茉奈の名前・女性・共犯者（見張り役）・幼なじみの友人であることをまとめて話す。
- 自白状態では自白後専用の質問だけが出て、聞けば隠していたことを話す（茉奈が手伝った理由／事件の日の経緯＝ダイヤ／盗んだ物の場所＝茉奈の家の庭／ダイヤの使い道／庭に埋めた経緯／茉奈への伝言）。
- 自白状態では「（取り調べの時間を延長する　＋3ターン）」が常に選べる（1ターン使って3ターン増える）。
- ルートの例：食事 → 守ろうとしている → 手料理 → 見つめる → 「自白」ボタン → 自白させる → 延長 → 事件の日 → 盗んだ物は今どこに → … → 回答で CLEAR 5/5（END 1）

### キャラクターの追加方法
`index.html` の `CHARACTERS` 配列に1人分のデータ（画像・初期値・秘密・フラグ定義・質問と返答・エンディング名）を追加する。書き方は田中のデータとファイル内のコメントを参照。
